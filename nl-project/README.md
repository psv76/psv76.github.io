# NEIROLINKS Project landing page

Статический одностраничник для GitHub Pages.

## Содержимое

- `index.html` — готовая страница.
- `assets/screens/` — скриншоты программы, Excel/PDF, DWG и Telegram-бота.
- `assets/logo/neiro_links_logo.svg` — логотип.
- `main-page-block.html` — заготовка блока-кнопки для главной страницы `psv76.github.io`.

## Как разместить на GitHub Pages

1. В репозитории `psv76.github.io` создать папку:

```text
/nl-project/
```

2. Скопировать в неё:

```text
index.html
assets/
```

3. Проверить локально или сразу открыть после публикации:

```text
https://psv76.github.io/nl-project/
```

4. На главной странице можно добавить блок из `main-page-block.html` или обычную кнопку:

```html
<a href="/nl-project/">Посмотреть NEIROLINKS Project</a>
```

## Примечание

Страница не использует внешние библиотеки, шрифты и CDN. Всё лежит локально и подходит для GitHub Pages.
